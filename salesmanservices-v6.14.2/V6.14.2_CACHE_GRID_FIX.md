# V6.14.2 — Sold grid cache fix

Root cause found: V6.14.1 changed `site.css` and `site.js`, but `site.html` still requested both assets with `?v=6.14.0`. Browsers/CDN could therefore keep the old CSS/JS, making the live Recently Sold section look unchanged.

Fixes:
- Asset cache keys bumped to `6.14.2`.
- Critical Recently Sold grid CSS is also embedded directly in `site.html`, so stale external CSS cannot force the cards into one column.
- Homepage HTML is returned with `Cache-Control: no-cache, no-store, must-revalidate`.
- Worker response exposes `X-Salesman-Version: 6.14.2` for deployment verification.
- Desktop: 3 columns; tablet: 2; mobile: 1.
