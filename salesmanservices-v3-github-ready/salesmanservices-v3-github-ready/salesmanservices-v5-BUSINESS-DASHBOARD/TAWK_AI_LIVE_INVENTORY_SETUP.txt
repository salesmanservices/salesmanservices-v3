SALESMAN SERVICES — TAWK.TO LIVE INVENTORY SETUP
=================================================

WHAT THIS UPDATE DOES
---------------------
Your /admin inventory remains the single source of truth.
When you add, edit, change a price, or mark an account Sold, the following URLs update automatically:

1) Human/crawler page:
   https://www.salesmanservices.com/ai-inventory

2) Plain text:
   https://www.salesmanservices.com/ai-inventory.txt

3) Structured JSON API:
   https://www.salesmanservices.com/api/ai-inventory

No new Cloudflare variables, passwords, emails, bindings, domains, or KV namespaces are required.

OPTION A — WEBSITE DATA SOURCE (EASIEST)
---------------------------------------
Use this unless your tawk.to plan supports the custom API integration you want.

1. Open tawk.to and select the Salesman Services property.
2. Go to Automation / AI Assist / Data Sources.
3. Open Website and click Add New.
4. Add:
   https://www.salesmanservices.com/ai-inventory
5. Make sure the URL is Enabled.
6. Run Re-crawl URL once after adding it.
7. If your plan supports Auto Update Schedule, enable the fastest schedule available on your plan.

Important: website crawling is scheduled, not instant. The live page updates instantly, but AI Assist learns the change at its next crawl.

OPTION B — CUSTOM API INTEGRATION (TRUE LIVE LOOKUP)
----------------------------------------------------
If your tawk.to AI Assist plan/interface supports custom API calls, use:

GET https://www.salesmanservices.com/api/ai-inventory?status=available

Useful filters:
- Available only:
  /api/ai-inventory?status=available
- Sold only:
  /api/ai-inventory?status=sold
- A type:
  /api/ai-inventory?status=available&type=Zerker
- Search:
  /api/ai-inventory?status=available&q=piety

No authentication is required because this endpoint contains only public listing data.

READY-TO-PASTE AI INSTRUCTIONS
------------------------------
Use the Salesman Services live inventory source as the source of truth for account stock and prices.

- Recommend only accounts whose status is "available".
- Never offer, reserve, or quote a sold account as available.
- Never invent account stock, prices, discounts, stats, quests, items, bans, or account history.
- Use the exact listed price when present. If a price is missing, say the customer must contact Discord for a quote.
- When no matching account is available, say it is currently out of stock and direct the visitor to Discord for alternatives.
- For purchases, negotiations, or a human agent, direct the visitor to the account's listed purchase link or the Salesman Services Discord.
- If live inventory conflicts with an older FAQ, document, or manual text source, trust the live inventory.

TESTS
-----
After deployment:
1. Open https://www.salesmanservices.com/api/health and confirm version 4.3.
2. Open https://www.salesmanservices.com/ai-inventory and confirm current stock.
3. In /admin, change one harmless price or status and save.
4. Refresh /ai-inventory and confirm the change appears.
5. Revert the test change.
6. Test AI Assist with:
   - What accounts are currently available?
   - Do you have any Zerkers?
   - What is the current price of [account name]?
   - Is [sold account name] available?
