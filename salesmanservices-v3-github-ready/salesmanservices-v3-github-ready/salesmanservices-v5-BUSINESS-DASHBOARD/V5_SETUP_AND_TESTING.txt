SALESMAN SERVICES V5 — DEPLOYMENT

1. Keep your working V4.3 branch/ZIP as backup.
2. Upload all V5 files to the same GitHub repository root.
3. After Cloudflare deploys, check and re-add ADMIN_PASSWORD and ADMIN_EMAIL if your build resets variables.
4. Keep the existing SALESMAN_DATA KV binding and ASSETS binding.
5. Open /api/health — version must be 5.0.
6. Open /admin, save once, then open Google Sheets and click Sync now.
7. Test the public calculator and /api/pricing.

GOOGLE SHEET
The detailed sheet ID is already configured. It must remain readable by anyone with the link so the Worker can import prices. V5 imports Skill Price, Quest List, Minigames and infcapes. It auto-syncs every six hours and keeps the previous working prices if a sync fails.
