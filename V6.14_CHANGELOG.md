# Salesman Services V6.14

## Customer experience
- Rebuilt checkout presentation with a 3-step progress indicator.
- Added clearer account, delivery-email and payment sections.
- Added automatic-delivery explanation before checkout.
- Added reservation/payment/delivery timeline so customers know what happens next.
- Improved payment and error states without changing the existing payment API contract.

## Mobile
- Account inventory collapses to one clean column on small screens.
- Sold accounts use responsive cards rather than a long single-image stack.
- Checkout sidebar, payment methods and consent controls adapt to narrow screens.
- Reduced hover movement on touch devices.

## Delivery
- Kept paid-order retry behavior for temporary email failures.
- Added explicit required secret names to Wrangler configuration.
- Added Resend/Cloudflare setup instructions without embedding credentials.

## Deployment hygiene
- Version bumped to 6.14.0.
- Added `.gitignore` protection for local secret files.
- Added `.dev.vars.example` with placeholder values only.
