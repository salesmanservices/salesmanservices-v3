SALESMAN SERVICES V5 — GITHUB/CLOUDFLARE DEPLOYMENT

1. Keep the working Sites V5 deployment as a backup.
2. Extract the corrected ZIP.
3. Upload its contents to the same GitHub repository root and replace the old
   V5 files.
4. Keep Cloudflare Root directory `/` and Production branch `main`.
5. Leave Build command empty or use `npm run build`.
6. Use Deploy command `npx wrangler deploy`.
7. Keep the SALESMAN_DATA KV binding in wrangler.jsonc.
8. Add ADMIN_PASSWORD with `npx wrangler secret put ADMIN_PASSWORD`.
9. Optionally add ADMIN_EMAIL with `npx wrangler secret put ADMIN_EMAIL`.
10. Open /api/health; version must be 5.0 and kv must be true.
11. Open /admin, save once, download a backup, and click Sync now.
12. Test the public calculator, /api/pricing and /api/ai-inventory.

The included Wrangler configuration automatically runs the build before
deployment. The shell scripts no longer require executable file permissions,
so GitHub browser uploads and Windows ZIP extraction are supported.

The public design, account pictures, listings, calculators, services and links
are preserved. V5 does not include BTC/LTC checkout or automatic payment
confirmation; those remain V6.
