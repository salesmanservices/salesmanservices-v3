# V6.14.1 Sold Accounts Fix

- Sold Accounts now uses its own dedicated responsive grid instead of inheriting `.account-grid`.
- Desktop: 3 cards per row.
- Tablet: 2 cards per row.
- Mobile: 1 card per row.
- Only the latest 6 sold listings are rendered on the homepage, preventing the page from growing indefinitely.
- Sold screenshots use `background-size: contain` so the full screenshot stays visible without cropping.
- Added stronger scoped CSS rules so later marketplace/mobile rules cannot override the sold layout.
